⚙️ Configuração inicial
Preencha os dados abaixo para conectar o sistema ao banco de dados compartilhado.
1
Firebase — URL do banco
console.firebase.google.com → Realtime Database → copie a URL no topo.
2
Firebase — API Key e Project ID
Configurações do projeto → Geral → Seus apps → </> → copie apiKey e projectId.
3
Chave da Anthropic (IA)
console.anthropic.com → API Keys → criar nova chave → cole abaixo.
⚠️ A chave Anthropic fica salva apenas no seu navegador (localStorage) e nunca é enviada para nenhum servidor externo além da API oficial da Anthropic.
